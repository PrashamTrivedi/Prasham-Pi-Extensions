Self-contained visual explainer · file:// safe · no network, no CDNs, inline CSS & JS only

transcript is scrolling & zooming — in A the strips never cover it; in B the rail stays pinned beside the editor

A · docked widget regions SAFE

  • Safe: no focus, text-cursor, or IME capture — widgets are ordinary lines.
  • Nothing overlaps the transcript: strips push the input down and consume rows.
  • Shares one region: duck + cockpit stack in the same full-width dock above the editor.
  • Eats rows: every strip takes terminal rows away from the chat.
  • No responsive gate: below 60 cols the cockpit collapses to a single summary line.
  • A′: move the cockpit below the editor so the two panels stop sharing one region.

B · separate side pane RISKY

  • True pinned pane: the rail is always visible and never covers chat.
  • Transcript stays full-width above the composite editor + rail region.
  • Must own focus, the text cursor, and IME candidate positioning.
  • IME risk: candidate popups and the caret can detach from the real input.
  • Verdict: risky — needs careful focus handoff between rail and editor.

Terminal columns: 50 – 160. Panels use box-drawing borders (╭ ─ ╮ │ ├ ┤ ╰ ╯). Drag the width slider below 60 to reveal the narrow-terminal collapse in A.
